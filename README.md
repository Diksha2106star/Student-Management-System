# Student Management System

A Java- based Student Management System built using Java,MySQL and JDBC.

# Project Overview

This project is designed to manage student information such as:
- Student ID
- Student Name
- Email
- Course
- Marks
- Grade
- Result

The project also demonstrates important Core Java concepts,Collections,Java 8 features, Multithreading, Synchronization , SQL and JDBC.
## Features
- Add Student
- View All Students
- Update Student Course
- Delete Student 
- Search Student Result
- Calculate Grade
- Display PASS/FAIL Result
- Store student data in MySQL
- HashMap for student data
- HashSet for unique courses
- Sorting using Java
- Lambda Expressions
- Stream API
- Multithreading
- Synchronization
- JDBC Database Connectivity

## 	Technologies Used

- Java
- MySQL
- SQL
- Collection Framework
- Java 8 Lambda Expressions
- Stream API
- Multithreading
- Synchronization
